# AIML Task 4 - Classification with Logistic Regression

## 🎯 Objective

Build a binary classification model using Logistic Regression on the Breast Cancer Wisconsin Dataset.

## 🛠 Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-Learn

## 📂 Dataset

Breast Cancer Wisconsin Dataset

## 📊 Tasks Performed

* Data Loading and Exploration
* Data Preprocessing
* Feature Standardization
* Logistic Regression Model Training
* Confusion Matrix Analysis
* Precision, Recall, F1 Score Calculation
* ROC-AUC Evaluation
* Threshold Tuning
* Sigmoid Function Visualization
* Feature Importance Analysis

## 📈 Generated Outputs

* Target Distribution
* Correlation Heatmap
* Confusion Matrix
* ROC Curve
* Precision Recall Curve
* Sigmoid Function Plot
* Threshold Analysis Plot
* Feature Importance Plot

## 🚀 How to Run

pip install -r requirements.txt

python task4_logistic_regression.py

## ✅ Conclusion

Successfully implemented Logistic Regression for breast cancer classification and evaluated model performance using multiple classification metrics and visualizations.
