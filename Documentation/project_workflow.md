# Project Workflow

1. Load Breast Cancer Dataset.
2. Perform data exploration and preprocessing.
3. Encode target variable (Malignant/Benign).
4. Split dataset into training and testing sets.
5. Standardize feature values using StandardScaler.
6. Train Logistic Regression model.
7. Generate predictions and prediction probabilities.
8. Evaluate model using Accuracy, Precision, Recall, F1 Score, and ROC-AUC.
9. Visualize Confusion Matrix and ROC Curve.
10. Perform Threshold Analysis.
11. Visualize Sigmoid Function.
12. Save evaluation reports, coefficients, and prediction results.
