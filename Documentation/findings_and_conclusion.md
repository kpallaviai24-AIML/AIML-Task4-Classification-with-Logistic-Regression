# Findings and Conclusion

## Findings

* Logistic Regression successfully classified breast cancer cases.
* Feature standardization improved model performance.
* ROC-AUC score demonstrated strong classification capability.
* Precision and Recall provided insights into prediction quality.
* Threshold tuning affected classification decisions significantly.
* Certain medical attributes contributed more strongly to diagnosis prediction.

## Conclusion

The Logistic Regression model effectively performs binary classification for breast cancer diagnosis. The model achieved strong performance based on Accuracy, Precision, Recall, F1 Score, and ROC-AUC metrics. Visualizations such as the ROC Curve, Confusion Matrix, and Sigmoid Function improved the interpretability of model behavior and prediction outcomes.
